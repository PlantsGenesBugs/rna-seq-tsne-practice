# RNA-seq t-SNE — Practice & Notes

This repository is my personal learning fork of the [Berens Lab RNA-seq t-SNE repository](https://github.com/berenslab/rna-seq-tsne).

The original repository accompanies:

> Kobak & Berens (2019), *The art of using t-SNE for single-cell transcriptomics.*

I am using the original notebooks and data to practice non-linear dimensionality reduction methods.

## Learning objectives

* Revise PCA as a linear dimensionality-reduction method
* Understand why PCA is commonly performed before t-SNE
* Understand the role of perplexity in t-SNE
* Investigate the effect of random initialisation
* Explore how t-SNE behaves under different parameter settings
* Compare t-SNE and UMAP

## Repository structure

### Original material

* `demo.ipynb` — original step-by-step analysis
* `toy-example.ipynb` — toy-data experiments
* `tasic-et-al.ipynb` — Tasic et al. analysis
* `umap-comparison.ipynb` — comparison involving UMAP

### My practice

* `01_demo_my_notes.ipynb` — annotated version of the demo
* `02_pca_experiments.ipynb` — experiments with PCA dimensionality
* `03_tsne_perplexity.ipynb` — experiments with t-SNE perplexity
* `04_tsne_vs_umap.ipynb` — comparison of t-SNE and UMAP
* `notes/` — concepts, questions and observations
